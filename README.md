# ניהול מכשירים – טכנודע

אתר לצוות לניהול מחשבים ניידים וטאבלטים. נכנסים לכתובת, מוסיפים ומעדכנים. האתר רץ על GitHub Pages, והנתונים נשמרים בקובץ `data/devices.json` בריפו, כך שכל שינוי נשמר בהיסטוריה ואפשר לשחזר אותו.

- **מחשבים וטאבלטים בנפרד**, לכל מכשיר מספר פנימי רץ החל מ-1. בכל הוספה המספר הבא מוצע אוטומטית, ואפשר לשנות אותו ידנית.
- **מספר סידורי של היצרן**: מוקלד ידנית. המערכת מתריעה אם הוא כבר רשום.
- **מצב**: תקין / תקול / בתיקון. בלחיצה על התגית בטבלה המצב מתחלף.
- **מערכת הפעלה ועדכון**: למשל "Windows 11", ו"מעודכן" או "צריך עדכון".
- **הערות**, חיפוש, סינון, ייצוא לאקסל וייבוא מאקסל.

---

## התקנה (פעם אחת, כ-10 דקות)

### 1. ריפו ואתר
1. ב-GitHub יוצרים ריפו חדש, למשל `technoda-devices`, ומעלים אליו את כל הקבצים מהתיקייה הזו (כולל `.nojekyll`).
2. ב-**Settings → Pages**: Source = `Deploy from a branch`, Branch = `main`, תיקייה `/ (root)`.
3. האתר יהיה זמין בכתובת `https://<שם-משתמש>.github.io/technoda-devices/`.

### 2. טוקן GitHub
**Settings (של המשתמש) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
- Repository access: **Only select repositories** ובוחרים את הריפו הזה.
- Repository permissions → **Contents: Read and write**.

### 3. שרת השמירה (Google Apps Script)
אתר על GitHub Pages לא יכול לשמור לבד. הסקריפט הקטן הזה שומר בשבילו ומחזיק את הטוקן בצד של Google, כך שהוא לא גלוי באתר.
1. נכנסים ל-[script.google.com](https://script.google.com) ← **New project**.
2. מוחקים את התוכן ומדביקים את הקוד מהקובץ [`apps-script/Code.gs`](apps-script/Code.gs).
3. ⚙️ **Project Settings** ← **Script Properties** ← מוסיפים:
   - `GITHUB_TOKEN` = הטוקן משלב 2
   - `GITHUB_REPO` = `שם-משתמש/technoda-devices`
4. **Deploy → New deployment** ← סוג **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים Deploy, מאשרים הרשאות ומעתיקים את ה-**Web app URL** (מסתיים ב-`/exec`).
5. בריפו עורכים את `data/config.json`:
   ```json
   {
     "orgName": "טכנודע",
     "apiUrl": "https://script.google.com/macros/s/XXXX/exec",
     "repo": "שם-משתמש/technoda-devices",
     "branch": "main"
   }
   ```

זהו. נכנסים לכתובת האתר ומתחילים להוסיף מכשירים.

## שימוש
- **הוספה:** "הוסף מכשיר" ← בוחרים מחשב או טאבלט ← המספר הבא כבר מולא ← מקלידים מספר סידורי ושאר הפרטים ← שמירה.
- **איפה המספר הסידורי:** במחשב, על המדבקה בתחתית (S/N). בטאבלט: הגדרות ← אודות הטאבלט ← מצב.
- **עריכה:** כפתור ✏️ בכל שורה. אפשר לשנות כל שדה, גם את המספר הפנימי.
- **ייבוא:** פותחים את הלשונית הרצויה (מחשבים או טאבלטים), לוחצים "ייבוא מאקסל" ובוחרים קובץ xlsx או csv. השורה הראשונה בקובץ היא שורת כותרות, עם אותם שמות כמו בייצוא: מספר, מספר סידורי, יצרן, דגם, מצב, מערכת, עדכון, הערות. אם המספר הסידורי כבר רשום, המכשיר מתעדכן, וכל השאר נוספים. הדרך הכי פשוטה: לייצא, לערוך באקסל ולייבא בחזרה.
- **הסרה:** ✏️ ← "הסר מהמלאי". המכשיר נשאר בהיסטוריה (סינון "הוסרו מהמלאי") ואפשר להחזיר אותו. "מחק לצמיתות" מוחק לגמרי.

## לדעת
- **לפני שמגדירים את שרת השמירה** אפשר כבר לעבוד: הנתונים נשמרים מקומית בדפדפן שבו עובדים, ולא במחשבים אחרים. כדאי לייצא לאקסל מדי פעם כגיבוי. אחרי שממלאים את `apiUrl` ופותחים את האתר באותו דפדפן, מופיע כפתור "העלה לשרת" שמעביר את כל המכשירים לקובץ המשותף.
- כל מי שיש לו את כתובת האתר יכול לראות ולערוך, ולכן לא מפרסמים אותה מחוץ לצוות.
- כל שינוי נשמר כ-commit בריפו, ואפשר לשחזר מההיסטוריה (קישור בתחתית האתר).
